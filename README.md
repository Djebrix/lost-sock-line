## The line

> Day 12 inside the dog's bed. He thinks I'm his. I've stopped correcting him — turns out the cuddles are elite.

## How it works

`main.py` (Python stdlib only) writes that single line to `/output/entry.txt`.
It asserts the line is 1–120 characters, a single line, and not only
whitespace, so the output always passes the kit's gate. The line is a fixed
string, so two runs produce byte-identical output.
